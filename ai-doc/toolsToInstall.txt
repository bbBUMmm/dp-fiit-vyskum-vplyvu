=== REQUIRED: 1) A TeX distribution ===

Option A - TeX Live (recommended: exact parity with the Mac setup, bundles Perl + biber + latexmk,
           no on-demand package prompts). ~8 GB, install takes 1-2 h.
  Download: https://tug.org/texlive/acquire-netinstall.html  ->  install-tl-windows.exe
  Run it, choose scheme-full, default paths. Not on winget.

Option B - MiKTeX (lighter, ~1 GB, installs packages on demand; then you MUST also install Perl).
  winget install --id MiKTeX.MiKTeX -e
  winget install --id StrawberryPerl.StrawberryPerl -e
  Then in MiKTeX Console: Settings -> "Always install missing packages on the fly" = Yes,
  and run Updates -> Check for updates once.
  Also make sure biber is present:  miktex packages install biber

Either option gives you: pdflatex, latexmk, biber, and all packages this thesis loads
(newpxtext/newpxmath, babel-slovak, biblatex, todonotes, algorithm/algpseudocode, pdfpages,
dirtytalk, csquotes, sverb, pmboxdraw, tabularx, booktabs, lipsum, listing, lscape).

=== REQUIRED: 2) VS Code extension ===
  code --install-extension James-Yu.latex-workshop

  Then add to VS Code settings.json so it builds into out\ like the Mac did:
    "latex-workshop.latex.outDir": "%DIR%/out",
    "latex-workshop.latex.recipe.default": "latexmk (latexmkrc)",
    "latex-workshop.latex.autoBuild.run": "onSave"
  (latexmk already runs biber automatically - no extra recipe needed.)
